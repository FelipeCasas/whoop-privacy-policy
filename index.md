# Privacy Policy: Luis Casas Personal Whoop App

_Last updated: October 30, 2026_

This app is a private, personal-use integration that lets Luis Casas access his own WHOOP data through the WHOOP API. It is not offered to the public, and no other users are served.

## Data accessed
With the account owner's authorization, the app reads WHOOP data such as profile, body measurements, recovery, heart rate variability, sleep, cycles, strain, and workouts.

## How data is used
Data is used only to give the account owner personal analysis and summaries of his own health and fitness records.

## Sharing
Data is never sold, rented, or shared with third parties, and is never used for advertising.

## Storage and security
Data and access tokens are stored privately and used only for the purposes above. Access can be revoked at any time from the WHOOP account settings, after which no new data is collected.

## Deletion
The account owner can request deletion of any stored data at any time.

Questions: contact the account owner through GitHub at https://github.com/FelipeCasas.
